# 🏫 Sistema de Reservas de Salas

Projeto desenvolvido como Trabalho de Conclusão de Curso (TFC) do curso de Engenharia de Controle e Automação da FAHOR.

## 🚀 Evolução do projeto

Este repositório corresponde à versão inicial do projeto **Sistema de Reservas de Salas**.

O projeto foi posteriormente **migrado para uma nova arquitetura**, separando a aplicação em frontend e backend, utilizando **Angular** no frontend e **Java com Spring Boot** no backend.

Os repositórios atuais do projeto são:

* 🖥️ **Frontend — Angular:** [sistema-reservas-web](https://github.com/EduardoRadieske/sistema-reservas-web)
* ⚙️ **Backend — Java / Spring Boot:** [sistema-reservas-api](https://github.com/EduardoRadieske/sistema-reservas-api)

### 📌 Status

Este repositório é mantido como **registro da versão inicial do projeto** e de sua evolução durante o desenvolvimento do TFC.

### 🧩 Arquitetura atual

A versão atual utiliza:

* **Frontend:** Angular
* **Backend:** Java + Spring Boot
* **Banco de dados:** PostgreSQL
* **Autenticação:** JWT
* **Integração:** API REST

O backend atual é responsável pelo gerenciamento de usuários, salas, horários, reservas e controle de acesso às fechaduras.

O frontend foi desenvolvido utilizando Angular.
